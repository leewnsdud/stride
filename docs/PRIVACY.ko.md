# 데이터 저장과 외부 전송

## 내 컴퓨터에 남는 정보

- `data/stride.sqlite`: 활동·상세 센서·GPS·훈련 계획·대화·AI 리뷰·삭제 복원 기록
- `data/garmin/`: Garmin 로그인 토큰
- `data/integrations.json`: 연동·모델 설정 (과거 연동 키가 남아 있을 수 있음)
- `data/remote-access.json`: 선택적으로 설정한 본인 원격 주소·계정
- `data/backups/`, 로그·JSON 내보내기: 개인 기록을 포함할 수 있음
- Codex 로그인 정보는 Codex가 관리하는 별도 사용자 디렉터리에 저장

DB·백업은 암호화되지 않습니다. 앱은 파일 권한을 제한하지만 같은 OS 계정과 관리자 접근을
차단하는 암호화 보관함은 아닙니다. 노트북 로그인 보호·디스크 암호화·백업 접근 권한을 관리하세요.
브라우저에는 UI 선택·초안 등의 상태가 남을 수 있으며, 서비스 워커는 API 응답을 캐시하지 않습니다.

## 외부 서비스

| 서비스 | 발생 시점 | 전달·요청하는 정보 |
| --- | --- | --- |
| Garmin Connect | 로그인·수동/예약 동기화 | 인증정보·인증코드·토큰, 활동 조회 범위 |
| OpenAI / Codex | 로그인·모델 조회·사용자가 AI 전송 | 질문, 선택한 활동의 메모·요약·센서 표본·연결 훈련·목표와 대화 문맥 |
| OpenFreeMap 등 지도 서비스 | GPS 지도 표시 | 지도 타일 요청과 접속 IP. 요청 타일로 대략적 지도 지역이 드러날 수 있음 |
| Google Fonts | 웹폰트 로드 | 폰트 요청과 접속 정보 |

AI용 활동 변환은 원본 응답·인증정보·GPS 좌표를 제외합니다. 그러나 **사용자가 질문이나
활동 메모에 직접 적은 개인정보는 텍스트로 전달될 수 있습니다.** 코칭에 필요하지 않은 정보는
입력하지 마세요. 리뷰 후속 대화는 원래 리뷰·당시 근거와 활동의 최신 기록을 함께 참고합니다.
외부 서비스에서 처리하는 데이터에는 각 서비스의 정책이 적용됩니다.

## 이 공개 저장소에 포함하지 않는 것

개인 DB, 토큰·비밀번호, 운영 로그, 내보낸 활동, 개인 GPS 파일, 대화 스크린샷,
실제 설치자의 원격 주소, 작업 세션 기록을 공개하지 않습니다.
테스트의 계정 문자열·활동·센서·좌표는 합성 예시이며 실제 사용자 내보내기 파일을 사용하지 않습니다.

`.gitignore`는 공개 파일을 허용 목록으로 관리합니다. 새 파일을 공개할 때는
`git diff --cached --stat`, `npm run check:privacy`, 별도 secret scanner로 확인하세요.
자동 검사는 모든 개인정보를 판별하지 못하므로 문서·이미지·테스트 fixture도 직접 검토해야 합니다.
한 번 공개된 데이터는 이후 파일을 지워도 외부 복사본에 남을 수 있습니다.

## 문제 제보

공개 이슈에 DB, 토큰 파일, 전체 로그, 실제 GPS 경로·대화 스크린샷을 첨부하지 마세요.
재현 단계와 개인정보를 제거한 오류 문구만 올려주세요. 보안 문제는 [보안 제보 안내](../SECURITY.md)를 따릅니다.
